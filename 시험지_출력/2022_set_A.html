1.
$3^3 \times 27^{-\dfrac{2}{3}}$의 값은? [2점]
①$3$②$4$③$5$④$6$⑤$7$
대수 · 지수와 로그 · Basic
정답 ① (3)
$$3^3 \times 27^{-\dfrac{2}{3}} = 3^3 \times (3^3)^{-\dfrac{2}{3}}$$ $$= 3^3 \times 3^{-2}$$ $$= 3^{3-2}$$ $$= 3^1 = 3$$ 따라서 정답은 ①이다.
2.
$0 \le x < 2\pi$일 때, 방정식 $$2\cos^2 x + 3\sin x - 3 = 0$$을 만족시키는 모든 실수 $x$의 값의 합은? [3점]
①$\pi$②$\dfrac{7\pi}{6}$③$\dfrac{4\pi}{3}$④$\dfrac{3\pi}{2}$⑤$\dfrac{5\pi}{3}$
대수 · 삼각함수 · Normal
정답 ④ (\frac{3\pi}{2})
$0 \le x < 2\pi$일 때, 방정식 $2\cos^2 x + 3\sin x - 3 = 0$에서 $\cos^2 x = 1 - \sin^2 x$이므로 $2(1 - \sin^2 x) + 3\sin x - 3 = 0$ $2\sin^2 x - 3\sin x + 1 = 0$ $(2\sin x - 1)(\sin x - 1) = 0$ $\sin x = \dfrac{1}{2}$ 또는 $\sin x = 1$ $0 \le x < 2\pi$에서 $\sin x = \dfrac{1}{2}$을 만족시키는 실수 $x$의 값은 $x = \dfrac{\pi}{6}$ 또는 $x = \dfrac{5\pi}{6}$이고, $\sin x = 1$을 만족시키는 실수 $x$의 값은 $x = \dfrac{\pi}{2}$이다. 따라서 주어진 방정식을 만족시키는 모든 실수 $x$의 값의 합은 $\dfrac{\pi}{6} + \dfrac{5\pi}{6} + \dfrac{\pi}{2} = \dfrac{3\pi}{2}$ 정답은 ④이다.
3.
다음 조건을 만족시키는 모든 수열 $\{a_n\}$에 대하여 $a_1$의 값의 합은? [4점]
(가)모든 자연수 $n$에 대하여 $$ a_{n+1} = \begin{cases} a_n + 4 & (a_n \le 0) \\ -\dfrac{1}{2}a_n + 3 & (a_n > 0) \end{cases} $$ 이다.
(나)$a_5 = 2$
①18②21③24④27⑤30
대수 · 수학적 귀납법 · Advanced
정답 ③ (24)
조건 (가)의 점화식을 $a_n$에 대하여 정리하면 다음과 같다. $a_n \le 0$일 때, $a_{n+1} = a_n + 4$이므로 $a_n = a_{n+1} - 4$이다. 이때 $a_n \le 0$이어야 하므로 $a_{n+1} \le 4$이다. $a_n > 0$일 때, $a_{n+1} = -\dfrac{1}{2}a_n + 3$이므로 $a_n = -2a_{n+1} + 6$이다. 이때 $a_n > 0$이어야 하므로 $a_{n+1} < 3$이다. 조건 (나)에서 $a_5 = 2$이므로 역추적하여 $a_4$를 구하면, $a_5 \le 4$이므로 $a_4 = 2 - 4 = -2$이고, $a_5 < 3$이므로 $a_4 = -2 \times 2 + 6 = 2$이다. 따라서 $a_4 \in \{-2, 2\}$이다. 같은 방법으로 $a_3, a_2, a_1$을 차례로 구한다. (i) $a_4 = -2$인 경우 $a_4 \le 4$이므로 $a_3 = -2 - 4 = -6$ $a_4 < 3$이므로 $a_3 = -2 \times (-2) + 6 = 10$ (ii) $a_4 = 2$인 경우 $a_4 \le 4$이므로 $a_3 = 2 - 4 = -2$ $a_4 < 3$이므로 $a_3 = -2 \times 2 + 6 = 2$ 따라서 가능한 $a_3$의 값은 $-6, 10, -2, 2$이다. 이어서 $a_2$를 구하면, $a_3 = -6$일 때, $-6 \le 4$에서 $a_2 = -10$, $-6 < 3$에서 $a_2 = 18$ $a_3 = 10$일 때, $10 \not\le 4$이고 $10 \not< 3$이므로 조건을 만족시키는 $a_2$는 존재하지 않는다. $a_3 = -2$일 때, $-2 \le 4$에서 $a_2 = -6$, $-2 < 3$에서 $a_2 = 10$ $a_3 = 2$일 때, $2 \le 4$에서 $a_2 = -2$, $2 < 3$에서 $a_2 = 2$ 따라서 가능한 $a_2$의 값은 $-10, 18, -6, 10, -2, 2$이다. 마지막으로 $a_1$을 구하면, $a_2 = -10$일 때, $-10 \le 4$에서 $a_1 = -14$, $-10 < 3$에서 $a_1 = 26$ $a_2 = 18$일 때, $18 \not\le 4$이고 $18 \not< 3$이므로 조건을 만족시키는 $a_1$은 존재하지 않는다. $a_2 = -6$일 때, $-6 \le 4$에서 $a_1 = -10$, $-6 < 3$에서 $a_1 = 18$ $a_2 = 10$일 때, 조건을 만족시키는 $a_1$은 존재하지 않는다. $a_2 = -2$일 때, $-2 \le 4$에서 $a_1 = -6$, $-2 < 3$에서 $a_1 = 10$ $a_2 = 2$일 때, $2 \le 4$에서 $a_1 = -2$, $2 < 3$에서 $a_1 = 2$ 결과적으로 조건을 만족시키는 모든 $a_1$의 값은 $-14, 26, -10, 18, -6, 10, -2, 2$이며, 이 모든 값의 합은 $(-14) + 26 + (-10) + 18 + (-6) + 10 + (-2) + 2 = 24$ 이다.

함수 $f(x)=2x^2-x+2$에 대하여 곡선 $y=f(x)$ 위의 점 $(1, 3)$에서의 접선의 기울기는? [2점]
①$0$②$1$③$2$④$3$⑤$4$
미적분Ⅰ · 미분계수 · Basic
정답 ④ (3)
곡선 $y=f(x)$ 위의 점 $(1, 3)$에서의 접선의 기울기는 함수 $f(x)$의 $x=1$에서의 미분계수 $f'(1)$과 같다. 함수 $f(x)=2x^2-x+2$에서 $f'(x)=4x-1$ 이므로 $f'(1)=4 \times 1 - 1 = 3$ 이다.
5.
다항함수 $f(x)$가 다음 조건을 만족시킨다.
(가)$\lim_{x \to \infty} \dfrac{f(x)}{x^2} = 2$
(나)$\lim_{x \to 1} \dfrac{f(x)}{x-1} = 5$
$f(2)$의 값은? [3점]
①$7$②$8$③$9$④$10$⑤$11$
미적분Ⅰ · 함수의 극한 · Normal
정답 ① (7)
조건 (가)에서 $\lim_{x \to \infty} \dfrac{f(x)}{x^2} = 2$이므로 $f(x)$는 최고차항의 계수가 $2$인 이차함수이다. $f(x) = 2x^2 + ax + b$ (단, $a$, $b$는 상수)라 하자. 조건 (나)의 $\lim_{x \to 1} \dfrac{f(x)}{x-1} = 5$에서 $x \to 1$일 때 (분모) $\to 0$이고 극한값이 수렴하므로 (분자) $\to 0$이어야 한다. 즉, 수렴 조건에 의하여 $\lim_{x \to 1} f(x) = 0$이므로 $f(1) = 2 + a + b = 0$에서 $b = -a - 2$이다. 이를 대입하여 식을 인수분해하면, 부정형을 해소할 수 있다. $f(x) = 2x^2 + ax - a - 2 = 2(x^2 - 1) + a(x - 1) = (x - 1)(2x + a + 2)$ 주어진 극한식에 대입하면 약분을 통해 $\dfrac{0}{0}$ 꼴의 부정형이 해소된다. $\lim_{x \to 1} \dfrac{f(x)}{x-1} = \lim_{x \to 1} \dfrac{(x - 1)(2x + a + 2)}{x - 1} = \lim_{x \to 1} (2x + a + 2) = a + 4$ 극한값이 $5$이므로 $a + 4 = 5$, 즉 $a = 1$이다. $a = 1$을 $b = -a - 2$에 대입하면 $b = -3$이다. 따라서 $f(x) = 2x^2 + x - 3$이므로 구하는 값은 $f(2) = 2 \times 2^2 + 2 - 3 = 7$이다.
6.
두 다항함수 $f(x)$, $g(x)$가 다음 조건을 만족시킨다.
(가)$\lim_{x \to 1} \dfrac{f(x) - 2}{x - 1} = 3$
(나)$\lim_{x \to 1} \dfrac{f(x) + g(x) - 5}{x - 1} = 4$
함수 $h(x) = 2f(x) - g(x)$에 대하여 $h'(1)$의 값은? [3점]
①$1$②$3$③$5$④$7$⑤$9$
미적분Ⅰ · 도함수 · Normal
정답 ③ (5)
조건 (가)에서 $x \to 1$일 때 분모가 $0$으로 가고 극한값이 존재하므로 분자도 $0$으로 간다. 즉, $\lim_{x \to 1} \{f(x) - 2\} = 0$에서 $f(1) = 2$이다. 미분계수의 정의에 의하여 $\lim_{x \to 1} \dfrac{f(x) - 2}{x - 1} = \lim_{x \to 1} \dfrac{f(x) - f(1)}{x - 1} = f'(1) = 3$이다. 조건 (나)에서 $x \to 1$일 때 분모가 $0$으로 가고 극한값이 존재하므로 분자도 $0$으로 간다. 즉, $\lim_{x \to 1} \{f(x) + g(x) - 5\} = 0$에서 $f(1) + g(1) = 5$이다. 미분계수의 정의에 의하여 $\lim_{x \to 1} \dfrac{f(x) + g(x) - 5}{x - 1} = \lim_{x \to 1} \dfrac{\{f(x) + g(x)\} - \{f(1) + g(1)\}}{x - 1} = f'(1) + g'(1) = 4$이다. $f'(1) = 3$이므로 $3 + g'(1) = 4$에서 $g'(1) = 1$이다. 함수 $h(x) = 2f(x) - g(x)$를 미분하면 $h'(x) = 2f'(x) - g'(x)$ 이므로 $x = 1$에서의 미분계수는 $h'(1) = 2f'(1) - g'(1) = 2 \times 3 - 1 = 5$이다. 따라서 정답은 ③이다.
7.
수직선 위를 움직이는 점 $\mathrm{P}$의 시각 $t$ ($t \ge 0$)에서의 속도 $v(t)$가 $$v(t) = \begin{cases} 3t^2 - 12t + 9 & (0 \le t \le 3) \\ a(3-t) & (t > 3) \end{cases}$$ 이다. 시각 $t=0$에서 점 $\mathrm{P}$의 위치는 $0$이다. 시각 $t$ ($t \ge 0$)에서의 점 $\mathrm{P}$의 위치를 $x(t)$라 하고, 시각 $0$에서 $t$까지 점 $\mathrm{P}$가 움직인 거리를 $s(t)$라 하자. 부등식 $s(t) - x(t) \ge 26$을 만족시키는 실수 $t$의 값의 범위가 $t \ge 5$일 때, 상수 $a$의 값은? (단, $a>0$이다.) [4점]
①$\dfrac{5}{2}$②$3$③$\dfrac{7}{2}$④$4$⑤$\dfrac{9}{2}$
미적분Ⅰ · 정적분의 활용 · Advanced
정답 ⑤ ($\frac{9}{2}$)
시각 $t$ ($t \ge 0$)에서의 점 $\mathrm{P}$의 위치 $x(t)$는 $x(t) = \int_{0}^{t} v(k) dk$ 이고, 시각 $0$에서 $t$까지 점 $\mathrm{P}$가 움직인 거리 $s(t)$는 $s(t) = \int_{0}^{t} |v(k)| dk$ 이다. $0 \le t \le 3$일 때, $v(t) = 3(t-1)(t-3)$이므로 $0 \le t \le 1$에서 $v(t) \ge 0$이고, $1 < t \le 3$에서 $v(t) < 0$이다. $0 \le t \le 3$에서의 $x(t)$와 $s(t)$를 구하면 다음과 같다. $x(3) = \int_{0}^{3} (3t^2 - 12t + 9) dk = \left[ t^3 - 6t^2 + 9t \right]_{0}^{3} = 27 - 54 + 27 = 0$ $s(3) = \int_{0}^{1} (3t^2 - 12t + 9) dk - \int_{1}^{3} (3t^2 - 12t + 9) dk = \left[ t^3 - 6t^2 + 9t \right]_{0}^{1} - \left[ t^3 - 6t^2 + 9t \right]_{1}^{3} = 4 - (-4) = 8$ $t > 3$일 때, $a>0$이므로 $v(t) = a(3-t) < 0$이다. 따라서 $t > 3$일 때 $x(t)$와 $s(t)$는 $x(t) = x(3) + \int_{3}^{t} a(3-k) dk = 0 + a \left[ 3k - \dfrac{1}{2}k^2 \right]_{3}^{t} = a \left( 3t - \dfrac{1}{2}t^2 - \dfrac{9}{2} \right) = -\dfrac{a}{2}(t-3)^2$ $s(t) = s(3) + \int_{3}^{t} |a(3-k)| dk = 8 + \int_{3}^{t} a(k-3) dk = 8 + a \left[ \dfrac{1}{2}k^2 - 3k \right]_{3}^{t} = 8 + a \left( \dfrac{1}{2}t^2 - 3t + \dfrac{9}{2} \right) = 8 + \dfrac{a}{2}(t-3)^2$ 이다. $s(t) - x(t) = \left\{ 8 + \dfrac{a}{2}(t-3)^2 \right\} - \left\{ -\dfrac{a}{2}(t-3)^2 \right\} = 8 + a(t-3)^2$ 이다. 한편, $0 \le t \le 3$에서는 $s(t) - x(t) = \int_{0}^{t} (|v(k)| - v(k)) dk$ 이고, 피적분함수가 $|v(k)| - v(k) \ge 0$이므로 이 구간에서 $s(t) - x(t)$는 최댓값 $s(3) - x(3) = 8$을 갖는다. 따라서 부등식 $s(t) - x(t) \ge 26$을 만족시키는 $t$는 $t > 3$ 범위에 존재한다. $t > 3$일 때, $8 + a(t-3)^2 \ge 26$에서 $a(t-3)^2 \ge 18$이다. $(t-3)^2 \ge \dfrac{18}{a}$ 이고, $t>3$이므로 $t - 3 \ge \sqrt{\dfrac{18}{a}}$, 즉 $t \ge 3 + \sqrt{\dfrac{18}{a}}$ 이다. 조건에서 부등식을 만족시키는 $t$의 값의 범위가 $t \ge 5$이므로 $3 + \sqrt{\dfrac{18}{a}} = 5$, $\sqrt{\dfrac{18}{a}} = 2$ 이다. 양변을 제곱하면 $\dfrac{18}{a} = 4$ 이므로 $a = \dfrac{9}{2}$ 이다.

두 사건 $A$, $B$가 서로 배반사건이고 $$P(A^C) = \dfrac{3}{4}, \quad P(A \cup B) = \dfrac{2}{3}$$ 일 때, $P(B)$의 값은? [2점]
①$\dfrac{1}{12}$②$\dfrac{1}{6}$③$\dfrac{1}{4}$④$\dfrac{1}{3}$⑤$\dfrac{5}{12}$
확률과통계 · 확률의 뜻과 활용 · Basic
정답 ⑤ (\frac{5}{12})
여사건의 확률의 성질에 의하여 $$P(A) = 1 - P(A^C) = 1 - \dfrac{3}{4} = \dfrac{1}{4}$$ 이다. 두 사건 $A$와 $B$가 서로 배반사건이므로 $$P(A \cap B) = 0$$ 이다. 확률의 덧셈정리에 의하여 $$P(A \cup B) = P(A) + P(B) - P(A \cap B) = P(A) + P(B)$$ 이므로 $$\dfrac{2}{3} = \dfrac{1}{4} + P(B)$$ 이다. 따라서 $P(B) = \dfrac{2}{3} - \dfrac{1}{4} = \dfrac{8}{12} - \dfrac{3}{12} = \dfrac{5}{12}$이다.

주머니 $\rm A$에는 흰 공 $2$개와 검은 공 $3$개가 들어 있고, 주머니 $\rm B$에는 흰 공 $3$개와 검은 공 $2$개가 들어 있다. 주머니 $\rm A$에서 임의로 $1$개의 공을 꺼내어 주머니 $\rm B$에 넣은 후, 주머니 $\rm B$에서 임의로 $1$개의 공을 꺼낼 때, 주머니 $\rm B$에서 꺼낸 공이 검은 공일 확률은? [3점]
①$\dfrac{11}{30}$②$\dfrac{2}{5}$③$\dfrac{13}{30}$④$\dfrac{7}{15}$⑤$\dfrac{1}{2}$
확률과통계 · 조건부확률 · Normal
정답 ③ (\frac{13}{30})
주머니 $\rm A$에서 흰 공을 꺼내는 사건을 $E_{1}$, 검은 공을 꺼내는 사건을 $E_{2}$라 하고, 주머니 $\rm B$에서 검은 공을 꺼내는 사건을 $E$라 하자. 주머니 $\rm A$에는 총 $5$개의 공 중 흰 공이 $2$개, 검은 공이 $3$개 들어 있으므로 $\mathrm{P}(E_{1}) = \dfrac{2}{5}$, $\mathrm{P}(E_{2}) = \dfrac{3}{5}$ (i) 주머니 $\rm A$에서 흰 공을 꺼내어 주머니 $\rm B$에 넣는 경우 주머니 $\rm B$에는 흰 공 $4$개, 검은 공 $2$개가 있게 되므로 주머니 $\rm B$에서 검은 공을 꺼낼 확률은 $\mathrm{P}(E|E_{1}) = \dfrac{2}{6} = \dfrac{1}{3}$ 이때의 확률은 확률의 곱셈정리에 의하여 $\mathrm{P}(E_{1} \cap E) = \mathrm{P}(E_{1})\mathrm{P}(E|E_{1}) = \dfrac{2}{5} \times \dfrac{1}{3} = \dfrac{2}{15}$ (ii) 주머니 $\rm A$에서 검은 공을 꺼내어 주머니 $\rm B$에 넣는 경우 주머니 $\rm B$에는 흰 공 $3$개, 검은 공 $3$개가 있게 되므로 주머니 $\rm B$에서 검은 공을 꺼낼 확률은 $\mathrm{P}(E|E_{2}) = \dfrac{3}{6} = \dfrac{1}{2}$ 이때의 확률은 확률의 곱셈정리에 의하여 $\mathrm{P}(E_{2} \cap E) = \mathrm{P}(E_{2})\mathrm{P}(E|E_{2}) = \dfrac{3}{5} \times \dfrac{1}{2} = \dfrac{3}{10}$ (i), (ii)의 두 사건은 서로 배반사건이므로 구하는 확률은 $\mathrm{P}(E) = \mathrm{P}(E_{1} \cap E) + \mathrm{P}(E_{2} \cap E) = \dfrac{2}{15} + \dfrac{3}{10} = \dfrac{4}{30} + \dfrac{9}{30} = \dfrac{13}{30}$

확률변수 $X$가 정규분포 $N(m, \sigma^2)$을 따르고, $Y=2X-4$이므로 $E(Y) = 2E(X) - 4 = 2m-4$, $V(Y) = 2^2 V(X) = 4\sigma^2$이다. 따라서 확률변수 $Y$는 정규분포 $N(2m-4, (2\sigma)^2)$을 따른다. 조건 (가)에서 $P(X \le 8) = P(Y \ge 8)$이고, $Z$가 표준정규분포를 따르는 확률변수일 때 $P(X \le 8) = P\left(Z \le \dfrac{8-m}{\sigma}\right)$ $P(Y \ge 8) = P\left(Z \ge \dfrac{8-(2m-4)}{2\sigma}\right) = P\left(Z \ge \dfrac{12-2m}{2\sigma}\right) = P\left(Z \ge \dfrac{6-m}{\sigma}\right)$이다. 표준정규분포곡선은 $z=0$에 대하여 대칭이므로 $\dfrac{8-m}{\sigma} = -\dfrac{6-m}{\sigma}$ $8-m = -6+m$, $2m = 14$, $m = 7$이다. 그러므로 $X \sim N(7, \sigma^2)$, $Y \sim N(10, (2\sigma)^2)$이다. 조건 (나)에서 $P(X \ge 10) + P(Y \le 4) = 0.1336$이고, $P(X \ge 10) = P\left(Z \ge \dfrac{10-7}{\sigma}\right) = P\left(Z \ge \dfrac{3}{\sigma}\right)$ $P(Y \le 4) = P\left(Z \le \dfrac{4-10}{2\sigma}\right) = P\left(Z \le -\dfrac{6}{2\sigma}\right) = P\left(Z \le -\dfrac{3}{\sigma}\right) = P\left(Z \ge \dfrac{3}{\sigma}\right)$ 이므로 $2 P\left(Z \ge \dfrac{3}{\sigma}\right) = 0.1336$, $P\left(Z \ge \dfrac{3}{\sigma}\right) = 0.0668$이다. 이때 $P\left(0 \le Z \le \dfrac{3}{\sigma}\right) = 0.5 - 0.0668 = 0.4332$이므로 표준정규분포표에서 $\dfrac{3}{\sigma} = 1.5$이다. 따라서 $\sigma = 2$이다. 그러므로 $X \sim N(7, 2^2)$, $Y \sim N(10, 4^2)$이다. $P(X \le 5) + P(Y \ge 18)$ $= P\left(Z \le \dfrac{5-7}{2}\right) + P\left(Z \ge \dfrac{18-10}{4}\right)$ $= P(Z \le -1) + P(Z \ge 2)$ $= P(Z \ge 1) + P(Z \ge 2)$ $= (0.5 - 0.3413) + (0.5 - 0.4772)$ $= 0.1587 + 0.0228 = 0.1815$이다. 정답은 2번이다.
