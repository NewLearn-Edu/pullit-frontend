1.
양의 실수 $a$와 실수 $x$에 대하여 $a^x = 3$, $a^{2x-1} = 1$일 때, $a$의 값은? [2점]
①$9$②$12$③$15$④$18$⑤$21$
수학I · 지수와 로그 · Basic
정답 ① (9)
$a^{2x-1} = 1$에서 $a$는 양의 실수이므로 다음 두 가지 경우로 나누어 생각할 수 있다. (i) $a=1$인 경우 $a^x = 1^x = 1$이 되므로, 조건 $a^x = 3$을 만족시키지 않는다. 따라서 $a \ne 1$이다. (ii) $a \ne 1$인 경우 $a \ne 1$이고 $a^{2x-1} = 1$이므로 지수가 $0$이어야 한다. 즉, $2x-1 = 0$에서 $x = \dfrac{1}{2}$ 이다. 이를 $a^x = 3$에 대입하면 $a^{\dfrac{1}{2}} = 3$ 이므로 양변을 제곱하면 $a = 9$ 이다. 구한 $a=9$, $x=\dfrac{1}{2}$을 원래 조건에 대입하면 $a^x = 9^{\dfrac{1}{2}} = 3$, $a^{2x-1} = 9^0 = 1$ 이 되어 모두 만족시킨다. 따라서 $a = 9$이다. 정답은 ①이다.
2.
함수 $$f(x) = \begin{cases} x^2 + ax & (x \ge 1) \\ b & (x < 1) \end{cases}$$ 이 $x=1$에서 미분가능할 때, $a+b$의 값은? (단, $a$, $b$는 상수이다.) [2점]
①$-4$②$-3$③$-2$④$-1$⑤$0$
수학II · 미분계수 · Basic
정답 ② (-3)
함수 $f(x)$가 $x=1$에서 미분가능하면 $x=1$에서 연속이므로 $\lim_{x \to 1^-} f(x) = f(1)$ 이 성립한다. $\lim_{x \to 1^-} f(x) = b$, $f(1) = 1+a$이므로 $b = 1+a$ …… ㉠ 한편, $x \ne 1$인 모든 실수 $x$에서 함수 $f(x)$는 미분가능하고 그 도함수 $f'(x)$는 $$f'(x) = \begin{cases} 2x+a & (x > 1) \\ 0 & (x < 1) \end{cases}$$ 이다. 함수 $f(x)$가 $x=1$에서 미분가능하므로 $\lim_{x \to 1^-} f'(x) = \lim_{x \to 1^+} f'(x)$ 가 성립해야 한다. $0 = 2+a$ $a = -2$ $a = -2$를 ㉠에 대입하면 $b = -1$ 따라서 $a+b = -2 + (-1) = -3$ 정답은 ②이다.
3.
$\dfrac{3}{2}\pi < \theta < 2\pi$인 $\theta$에 대하여 $$ \dfrac{\cos \theta}{1 + \sin \theta} + \dfrac{\cos \theta}{1 - \sin \theta} = 4 $$ 일 때, $\sin \theta - \tan \theta$의 값은? [3점]
①$-\dfrac{\sqrt{3}}{2}$②$\dfrac{\sqrt{3}}{2}$③$\sqrt{3}$④$\dfrac{3\sqrt{3}}{2}$⑤$2\sqrt{3}$
수학I · 삼각함수 · Normal
정답 ② ($\frac{\sqrt{3}}{2}$)
$$\dfrac{\cos \theta}{1 + \sin \theta} + \dfrac{\cos \theta}{1 - \sin \theta} = \dfrac{\cos \theta(1 - \sin \theta) + \cos \theta(1 + \sin \theta)}{(1 + \sin \theta)(1 - \sin \theta)}$$ $$= \dfrac{2\cos \theta}{1 - \sin^2 \theta} = \dfrac{2\cos \theta}{\cos^2 \theta} = \dfrac{2}{\cos \theta}$$ 주어진 방정식에서 $\dfrac{2}{\cos \theta} = 4$이므로 $\cos \theta = \dfrac{1}{2}$이다. $\dfrac{3}{2}\pi < \theta < 2\pi$이므로 $\sin \theta < 0$이다. $\sin^2 \theta = 1 - \cos^2 \theta = 1 - \dfrac{1}{4} = \dfrac{3}{4}$이므로 $\sin \theta = -\dfrac{\sqrt{3}}{2}$이다. $\tan \theta = \dfrac{\sin \theta}{\cos \theta} = \dfrac{-\dfrac{\sqrt{3}}{2}}{\dfrac{1}{2}} = -\sqrt{3}$ 따라서 $\sin \theta - \tan \theta = -\dfrac{\sqrt{3}}{2} - (-\sqrt{3}) = \dfrac{\sqrt{3}}{2}$
4.
닫힌구간 $[-2, 3]$에서 정의된 함수 $f(x)$가 $$ f(x) = \begin{cases} 2x+a & (-2 \le x < 0) \\ -x^2+4x+b & (0 \le x \le 3) \end{cases} $$ 이다. 함수 $f(x)$가 닫힌구간 $[-2, 3]$에서 연속이고 최댓값이 $10$일 때, 함수 $f(x)$의 최솟값은? (단, $a$, $b$는 상수이다.) [3점]
①$1$②$2$③$3$④$4$⑤$5$
수학II · 함수의 연속 · Normal
정답 ② (2)
함수 $f(x)$가 닫힌구간 $[-2, 3]$에서 연속이므로 $x=0$에서도 연속이어야 한다. $\lim_{x \to 0-} f(x) = \lim_{x \to 0-} (2x+a) = a$ $\lim_{x \to 0+} f(x) = \lim_{x \to 0+} (-x^2+4x+b) = b$ $f(0) = b$ 따라서 $a=b$이다. 닫힌구간 $[-2, 3]$에서 함수 $f(x)$의 식을 $a$로 나타내면 $$ f(x) = \begin{cases} 2x+a & (-2 \le x < 0) \\ -x^2+4x+a & (0 \le x \le 3) \end{cases} $$ 이다. $0 \le x \le 3$일 때, $f(x) = -(x-2)^2+a+4$이므로 $x=2$에서 최댓값 $a+4$를 갖는다. $-2 \le x < 0$일 때, $f(x) = 2x+a$는 증가하는 함수이고 $f(x) < a$이므로, 함수 $f(x)$의 최댓값은 $a+4$이다. 조건에서 함수 $f(x)$의 최댓값이 $10$이므로 $a+4 = 10$, 즉 $a=6$이다. 따라서 $b=6$이고, $$ f(x) = \begin{cases} 2x+6 & (-2 \le x < 0) \\ -x^2+4x+6 & (0 \le x \le 3) \end{cases} $$ 이다. 닫힌구간 $[-2, 3]$에서 함수 $f(x)$의 최솟값을 구하기 위해 구간별 값의 범위를 확인하면, $-2 \le x < 0$에서 $f(x)$는 증가하므로 $x=-2$일 때 최솟값 $f(-2) = 2$를 갖는다. $0 \le x \le 3$에서 $f(0)=6$, $f(3)=-9+12+6=9$이므로 이 구간에서 최솟값은 $6$이다. 따라서 닫힌구간 $[-2, 3]$에서 함수 $f(x)$의 전체 최솟값은 $2$이다. 따라서 정답은 ②이다.
5.
다항함수 $f(x)$가 모든 실수 $x$에 대하여 $$ \int_{1}^{x} f(t) dt = x^3 + ax^2 - 5x + b $$ 를 만족시키고 $f(1) = 2$일 때, $f(a)+b$의 값은? (단, $a$, $b$는 상수이다.) [3점]
①$17$②$18$③$19$④$20$⑤$21$
수학II · 정적분 · Normal
정답 ① (17)
주어진 등식 $\int_{1}^{x} f(t) dt = x^3 + ax^2 - 5x + b$ 의 양변을 $x$에 대하여 미분하면 $f(x) = 3x^2 + 2ax - 5$ $f(1) = 2$이므로 $3 + 2a - 5 = 2$, $2a = 4$ $a = 2$ 주어진 등식의 양변에 $x=1$을 대입하면 $\int_{1}^{1} f(t) dt = 1^3 + a \times 1^2 - 5 \times 1 + b$ 이므로 $0 = 1 + 2 - 5 + b$, $b = 2$ 따라서 $f(x) = 3x^2 + 4x - 5$이므로 $f(a)+b = f(2)+2 = (12 + 8 - 5) + 2 = 17$ 따라서 정답은 ①이다.
6.
공비가 정수인 등비수열 $\{a_n\}$이 다음 조건을 만족시킨다.
(가)$|a_2|+a_5=54$
(나)$a_1+a_4=-21$
$a_5$의 값은? [4점]
①$12$②$24$③$36$④$48$⑤$60$
수학I · 등차수열과 등비수열 · Advanced
정답 ④ (48)
등비수열 $\{a_n\}$의 첫째항을 $a$, 공비를 $r$라 하자. (단, $a \neq 0$이고 $r$는 정수) 조건 (나)에서 $a + ar^3 = -21$이므로 $a(1+r^3) = -21$ $\cdots$ ㉠ 조건 (가)에서 $|ar| + ar^4 = 54$이다. (i) $a_2 = ar \ge 0$인 경우 $ar + ar^4 = 54$이므로 $ar(1+r^3) = 54$ $\cdots$ ㉡ ㉠, ㉡에서 $1+r^3 \neq 0$이므로 양변을 나누면 $\dfrac{ar(1+r^3)}{a(1+r^3)} = \dfrac{54}{-21}$ $r = -\dfrac{18}{7}$ 이는 $r$가 정수라는 조건에 모순이다. (ii) $a_2 = ar < 0$인 경우 $-ar + ar^4 = 54$이므로 $ar(r^3-1) = 54$ $\cdots$ ㉢ ㉢을 ㉠으로 나누면 ($a \neq 0$이고 $r \neq -1$이므로) $\dfrac{ar(r^3-1)}{a(r^3+1)} = \dfrac{54}{-21}$ $\dfrac{r(r^3-1)}{r^3+1} = -\dfrac{18}{7}$ $7r(r^3-1) = -18(r^3+1)$ $7r^4 - 7r = -18r^3 - 18$ $7r^4 + 18r^3 - 7r + 18 = 0$ 조립제법을 이용하여 인수분해하면 $(r+2)(7r^3 + 4r^2 - 8r + 9) = 0$이다. $r$는 정수이므로 $r = -2$이다. (방정식 $7r^3 + 4r^2 - 8r + 9 = 0$은 정수해를 갖지 않는다.) $r = -2$를 ㉠에 대입하면 $a\{1 + (-2)^3\} = -21$ $-7a = -21$, 즉 $a = 3$이다. 이때 $a_2 = ar = 3 \times (-2) = -6 < 0$이므로 가정에 모순되지 않는다. 따라서 등비수열 $\{a_n\}$의 일반항은 $a_n = 3 \times (-2)^{n-1}$이므로 $a_5 = 3 \times (-2)^4 = 3 \times 16 = 48$이다.

1.
두 집합 $X=\{1, 2, 3\}$, $Y=\{1, 2, 3, 4, 5\}$에 대하여 함수 $f:X \to Y$ 중에서 $f(1)=2$를 만족시키는 함수 $f$의 개수는? [2점]
①5②10③15④20⑤25
확률과통계 · 순열과 조합 · Basic
정답 ⑤ (25)
함수 $f:X \to Y$ 중에서 $f(1)=2$이므로 정의역 $X$의 원소 $1$에 대응하는 공역 $Y$의 원소를 정하는 경우의 수는 $1$이다. 정의역 $X$의 나머지 두 원소 $2$, $3$에 각각 대응하는 공역 $Y$의 원소를 정하는 경우의 수는 서로 다른 $5$개에서 중복을 허락하여 $2$개를 택하는 중복순열의 수와 같으므로 ${}_5\Pi_2 = 5^2 = 25$ 이다. 따라서 구하는 함수 $f$의 개수는 $1 \times 25 = 25$ 이다.
2.
두 사건 $A$, $B$가 서로 독립이고 $$ \mathrm{P}(A^C \mid B) = \dfrac{2}{3}, \quad \mathrm{P}(B^C \mid A) = \dfrac{1}{2} $$ 일 때, $\mathrm{P}(A \cup B)$의 값은? (단, $A^C$, $B^C$은 각각 사건 $A$, $B$의 여사건이고, $\mathrm{P}(A)>0$, $\mathrm{P}(B)>0$이다.) [3점]
①$\dfrac{7}{12}$②$\dfrac{2}{3}$③$\dfrac{3}{4}$④$\dfrac{5}{6}$⑤$\dfrac{11}{12}$
확률과통계 · 조건부확률 · Normal
정답 ② (\frac{2}{3})
두 사건 $A$, $B$가 서로 독립이므로 $$ \mathrm{P}(A^C \mid B) = \mathrm{P}(A^C), \quad \mathrm{P}(B^C \mid A) = \mathrm{P}(B^C) $$ 이다. 주어진 조건에서 $\mathrm{P}(A^C) = \dfrac{2}{3}$, $\mathrm{P}(B^C) = \dfrac{1}{2}$이므로 $$ \mathrm{P}(A) = 1 - \mathrm{P}(A^C) = \dfrac{1}{3} $$ $$ \mathrm{P}(B) = 1 - \mathrm{P}(B^C) = \dfrac{1}{2} $$ 이다. 두 사건 $A$, $B$가 서로 독립이므로 $$ \mathrm{P}(A \cap B) = \mathrm{P}(A)\mathrm{P}(B) = \dfrac{1}{3} \times \dfrac{1}{2} = \dfrac{1}{6} $$ 이다. 따라서 확률의 덧셈정리에 의하여 $$ \mathrm{P}(A \cup B) = \mathrm{P}(A) + \mathrm{P}(B) - \mathrm{P}(A \cap B) = \dfrac{1}{3} + \dfrac{1}{2} - \dfrac{1}{6} = \dfrac{2}{3} $$ 이다.
3.
이산확률변수 $X$가 가지는 값은 $1, 2, a, b$이다. $X$의 확률질량함수가 다음 조건을 만족시킨다.
(가)$P(X=1)=P(X=b)=\dfrac{1}{8}$
(나)$P(X=2)=P(X=a)$
$X$의 평균이 $4$이고 분산이 자연수일 때, $a+b$의 값은? (단, $a, b$는 $2 < a < b$인 자연수이다.) [4점]
①$17$②$19$③$21$④$23$⑤$25$
확률과통계 · 확률분포 · Advanced
정답 ② (19)
이 문항은 주어진 확률질량함수와 기댓값 조건을 통해 미지수 $a, b$의 후보를 생성하고, 분산 조건을 이용하여 최종적으로 유일한 순서쌍 $(a, b)$를 확정하는 것을 목표로 한다. 확률변수 $X$가 가지는 값은 $1, 2, a, b$로 총 4개이다. **1. 분포 성립 조건 점검** 확률분포표를 완성하기 위해 먼저 전체 확률의 합이 $1$이어야 함을 점검해야 한다. 주어진 조건에서 $P(X=1) = P(X=b) = \dfrac{1}{8}$이고, $P(X=2) = P(X=a)$이다. 확률의 총합은 $1$이므로 $$ P(X=1) + P(X=2) + P(X=a) + P(X=b) = 1 $$ $$ \dfrac{1}{8} + P(X=2) + P(X=2) + \dfrac{1}{8} = 1 $$ $$ 2P(X=2) = \dfrac{3}{4} $$ 따라서 $P(X=2) = P(X=a) = \dfrac{3}{8}$이다. **2. 수치조건 해석 및 후보 생성** 다음으로 기댓값 $E(X) = 4$라는 수치조건을 해석하여 가능한 자연수 $a, b$의 관계식을 구한다. $$ E(X) = 1 \times \dfrac{1}{8} + 2 \times \dfrac{3}{8} + a \times \dfrac{3}{8} + b \times \dfrac{1}{8} = \dfrac{1 + 6 + 3a + b}{8} $$ $$ \dfrac{7 + 3a + b}{8} = 4 $$ $$ 3a + b = 25 $$ 단, $a, b$는 $2 < a < b$인 자연수이므로 이를 만족시키는 순서쌍 $(a, b)$의 후보를 생성하면 다음과 같다. $a=3$일 때 $b=16$ ($3 < 16$ 만족) $a=4$일 때 $b=13$ ($4 < 13$ 만족) $a=5$일 때 $b=10$ ($5 < 10$ 만족) $a=6$일 때 $b=7$ ($6 < 7$ 만족) ($a=7$이면 $b=4$가 되어 $a < b$ 조건에 위배된다.) **3. 가능·불가능 판정 및 최종값 확정 (유일성 확인)** 후보들 중 기댓값 조건만으로는 $a, b$가 유일하게 결정되지 않으므로, 분산 $V(X)$가 자연수라는 조건을 통해 가능·불가능을 판정하여 유일한 경우를 찾아야 한다. $V(X) = E(X^2) - \{E(X)\}^2 = E(X^2) - 16$이므로, $E(X^2)$을 계산하여 확인한다. $$ E(X^2) = 1^2 \times \dfrac{1}{8} + 2^2 \times \dfrac{3}{8} + a^2 \times \dfrac{3}{8} + b^2 \times \dfrac{1}{8} = \dfrac{13 + 3a^2 + b^2}{8} $$ ① $(a, b) = (3, 16)$인 경우 $E(X^2) = \dfrac{13 + 27 + 256}{8} = \dfrac{296}{8} = 37$ $V(X) = 37 - 16 = 21$ (자연수이므로 조건 만족) ② $(a, b) = (4, 13)$인 경우 $E(X^2) = \dfrac{13 + 48 + 169}{8} = \dfrac{230}{8} = \dfrac{115}{4}$ $V(X) = \dfrac{115}{4} - 16 = \dfrac{51}{4}$ (자연수가 아니므로 모순) ③ $(a, b) = (5, 10)$인 경우 $E(X^2) = \dfrac{13 + 75 + 100}{8} = \dfrac{188}{8} = \dfrac{47}{2}$ $V(X) = \dfrac{47}{2} - 16 = \dfrac{15}{2}$ (자연수가 아니므로 모순) ④ $(a, b) = (6, 7)$인 경우 $E(X^2) = \dfrac{13 + 108 + 49}{8} = \dfrac{170}{8} = \dfrac{85}{4}$ $V(X) = \dfrac{85}{4} - 16 = \dfrac{21}{4}$ (자연수가 아니므로 모순) 따라서 유일성 검증을 통해 조건을 만족시키는 순서쌍은 $(a, b) = (3, 16)$뿐임이 확정된다. 최종적으로 구하는 값은 $a+b = 3+16 = 19$이다.
