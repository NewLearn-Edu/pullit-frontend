## 버전 이력

### v1 — Minimal Coral (Airbnb 기반 웜미니멀) ✅ 박제됨
- **파일:** `checkpoints/v1-minimal-coral.html`
- **저장일:** 2026-06-15
- **컨셉:** "일단 풀어. 1등급 가능해. 하루 3문제." — 군더더기 없이 메시지 중심
- **브랜드:** Pullit (it = 코랄 강조)
- **무드:** 밝은 흰 배경, 웜미니멀, 압도적 여백. (대표 피드백: "너무 미니멀해서 다른 브랜드랑 똑같아 보임" → v2에서 차별화 예정)

#### 디자인 토큰 (컨플 디자인 시스템 — Airbnb 코랄)
| 역할 | 값 |
| --- | --- |
| 브랜드 코랄 | `#ff385c` (active `#e00b41`) |
| 본문 웜블랙 | `#222222` (순검정 금지) |
| 보조 텍스트 | `#6a6a6a` |
| 캔버스 / 서피스 | `#ffffff` / `#f7f7f7` |
| 헤어라인 | `#dddddd` |
| 숙련도 — 약점/보통/강점 | `#ff385c` / `#ef9f27` / `#1d9e75` |
| 폰트 | Pretendard, 헤딩 음수 자간, 700~800 |
| 라운드 | 버튼 8 / 뱃지 14 / 카드 20 / pill 9999 |
| 카드 그림자 | 3겹 (rgba 0.02 0 0 0 1px, 0.04 0 2px 6px, 0.1 0 4px 8px) |

#### 섹션 구조 (배경 교차)
1. **히어로** (흰색) — `일단 풀어. / 1등급 가능해.` + CTA + "회원가입 없이 1분"
2. **AI Pick** (회색) — `매일 3문제, AI가 골라줌` + 무작위 기출 NO + 추천 카드 3개(삼각함수·빈칸추론·도함수, 숙련도 진행바)
3. **Proof** (흰색) — `왜 3문제로 충분하냐면, 아무 문제나가 아니라 네 약점만 주거든.`
4. **3 Steps** (회색) — `이게 전부야.` 일단 푼다 → 약점이 보인다 → 매일 3문제 푼다
5. **마지막 CTA** (흰색) — `오늘 3문제면, 시작이야.`
6. **푸터**

#### 카피 톤
- 따뜻한 코칭 톤(같이 약점 잡아주는 코치), 반말. 압박·결핍·과장 금지.
- 카드 좌측 색띠 ❌ (대표가 싫어함 — 절대 넣지 말 것)

### v2 — Dark Cinematic Hero ✅ 현재 라이브
- **파일:** `checkpoints/v2-dark-cinematic.html` (= 현재 `index.html`)
- **저장일:** 2026-06-15
- **배경:** v1이 "너무 정석 미니멀이라 변별력 없음"(대표 피드백). 대표가 만든 [Pullit cyan](https://pullit-cyan.vercel.app/)(다크·네온·시네마틱)의 개성을 가져오되 절제.
- **변경점 (v1 대비 — 히어로만 교체, 본문은 v1 그대로):**
  - 히어로 = **다크 배경(`#160f0e` 웜다크) + 코랄 글로우(radial)** + 거대한 반투명 `3` 모티프 + 떠다니는 수식(π·∫·Σ·lim·x², opacity 0.07, drift 애니메이션)
  - 타이틀 코랄 글로우 text-shadow, CTA 코랄 글로우 그림자
  - **nav = `position:fixed`** → 히어로 위에선 투명·흰 워드마크, 스크롤 40px↓ 시 `.scrolled`(흰 블러 배경·검은 워드마크). JS는 `</body>` 직전 스크롤 리스너.
  - **AI Pick 섹션도 다크로 확장**(2026-06-15 추가): 히어로→AI Pick 까지 "다크 시네마틱 존", 그 아래 Proof부터 다시 밝게. 카드 = 다크 글래스(`#211a18` + 흰 보더 8% + 호버 시 코랄 보더·상승), 진행바 트랙 어둡게, 약점 진행바 코랄 글로우. 숙련도 라벨 색 다크 가독용으로 조정(약점 `#ff7088`·보통 `#f0b24a`·강점 `#2dd4a0`).
  - **수식 우주 파티클**: 히어로에 JS 파티클 26개(수식+작은 사각), 각자 속도·회전으로 부유하며 가장자리 wrap. 흰색 저투명 위주 + 코랄 포인트. `prefers-reduced-motion` 시 정지.
  - **전체 다크 전환**(2026-06-15): 페이지 전 섹션 다크로 통일. 명도 층 — 본문 `#160f0e`(히어로·픽·스텝) ↔ `#1b1412`(프루프·CTA) ↔ `#120c0b`(푸터). 마지막 CTA는 코랄 글로우(히어로와 수미상관). nav 스크롤 시 다크 블러. 3스텝 카드도 글래스화.
  - 숙련도 색 톤다운: 보통 `#e0b46a`(앰버)·강점 `#62c4a0`(세이지민트), 약점은 코랄 유지. AI Pick 카드 'AI 추천' 태그 제거.
- **유지:** 코랄 액센트 원칙, 카드 좌측 색띠 금지, 코칭 톤. (v1은 밝은 버전으로 `checkpoints/v1-minimal-coral.html` 보존)

#### 현재 섹션 구성 (2026-06-16 기준)
1. **히어로**(다크+코랄글로우+수식우주) — "일단 풀어. 1등급 가능해." + 라이브 카운터(오도미터, 13,472부터 천천히 증가)
2. **AI Pick** — "매일 3문제, AI가 골라줌" + 글래스 카드 3개(과목 라벨 수학/영어, 숙련도 진행바)
3. **문제 제작 파이프라인** — "그냥 AI 문제가 아니야. 연구원이 분석한 기출에서 나와." 기출 해부→출제 원리→AI 생성 3-stage(STEP3만 코랄)
4. **Proof** — "왜 3문제로 충분하냐면, 네 약점만 주거든."
5. **성적 상승 그래프**(신규, 구 '이게 전부야' 3스텝 대체) — "쌓이면, 성적이 움직여." SVG 라인차트(4등급→1등급, 스크롤 시 그려짐) + 스탯 3개. *반복 메시지 제거 목적*
6. **마지막 CTA**(코랄 글로우) — "오늘 3문제면, 시작이야."
7. **푸터**
